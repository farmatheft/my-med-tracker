## Крок 3 — Розділення башт на групи по 10 таблеток

- [x] **Файли:** `src/components/IntakePanel.jsx` (AnimatedTowerArea + логіка MAX_PILLS)
- **Що:** Зараз `MAX_PILLS_PER_TYPE = 10` обмежує максимум таблеток. Потрібно дозволити більше та при >10 таблетках створювати нову башту того ж типу поруч.
- **Як:**
  - Збільшити `MAX_PILLS_PER_TYPE` до 20 (або прибрати обмеження).
  - В `AnimatedTowerArea` змінити логіку побудови `towers[]`: якщо `count > 10`, створювати декілька башт:
    ```js
    if (count5 > 0) {
      const fullTowers = Math.floor(count5 / 10);
      const remainder = count5 % 10;
      for (let i = 0; i < fullTowers; i++)
        list.push({ key: `5-${i}`, type: '5', count: 10, width: ... });
      if (remainder > 0)
        list.push({ key: `5-${fullTowers}`, type: '5', count: remainder, width: ... });
    }
    ```
  - Пов'язані башти одного типу сортувати поруч.

## Крок 4 — Прибрати/покращити анімацію додавання таблеток

- [x] **Файли:** `src/components/PillTower.jsx`, `src/components/IntakePanel.jsx`
- **Що:** Зараз є анімація `pillFallIn` (падіння зверху) з bounce-ефектом при додаванні та `pillFlyOut` при видаленні. Це викликає "дьоргання" інтерфейсу, особливо при швидкому натисканні.
- **Як:**  
  - Замінити анімацію додавання на швидкий `fadeIn + scaleIn` на місці (без translateY):
    ```css
    @keyframes pillAppear {
      0% { opacity: 0; transform: scale(0.7); }
      100% { opacity: 1; transform: scale(1); }
    }
    ```
  - Тривалість: 150ms (замість 400ms).
  - Прибрати shake-анімацію башти (`pillShake`) — вона додає нестабільність.
  - Видалення: швидкий `fadeOut + scaleOut` за 120ms (замість 350ms flyOut).

- [x] **Файли:** `src/index.css`, `src/components/IntakePanel.jsx`
- **Що:** Galaxy A17 має CSS viewport ~384px шириною. Потрібно переконатися, що немає горизонтальних скролів.
- **Як:**
  - Перевірити всі ширини в IntakePanel: таби таблеток, башти, кнопки +/− — все має поміщатися в 384px з padding.
  - Максимальна ширина зони башт: `calc(100vw - 24px)` з `overflow-x: hidden`.
  - Множинні башти (крок 3): якщо їх стає надто багато по ширині, використати `flex-wrap: wrap` з маленьким gap.
  - Тестувати з `@media (max-width: 420px)` для fine-tuning.
